# Logo assets

SVG and 512 × 512 transparent PNG artwork from the
[libtmux logo kit](https://github.com/libtmux/assets), revision
`b4c5d4a83eb54de90119ec402b41d706211a2716` (`assets/perl/library`).

Library marks use the cog, workspace marks the tiled tmuxp base, and MCP
marks the Model Context Protocol symbol. Perl's `#0298C3` primary tile color
follows [GitHub Linguist][linguist]. The source libtmux and tmuxp artwork
belongs to the project owner. The MCP symbol comes from the
[upstream logo][mcp-logo].

Package-specific artwork sits beside its `README.md` under `packages/*/assets/`
(`packages/core` and `packages/async` carry the library mark;
`packages/workspace` carries `assets/perl/workspace` from the same kit
revision). `.github/social-preview.png` is the cog sharing card, ready to
upload under the repository's **Settings → Social preview**.

The sharing card comes from `assets/perl/library/opengraph-light.png` at kit
revision `a6377dd4fbfe0d5e59271ceefb21cb503646dbc0`.
