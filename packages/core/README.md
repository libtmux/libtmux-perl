# LibTmux

Core Perl distribution for libtmux, currently a package scaffold targeting
Perl 5.44. It declares no runtime dependencies outside Perl's standard library.
The client API and runtime tests are not implemented yet.

The unpublished development version is `0.001_001`. This directory owns its
native distribution metadata. The separate workspace distribution depends
on the core's public API; tmux protocol and transport belong here.

See the [repository contribution guide](https://github.com/libtmux/libtmux-perl/blob/master/.github/CONTRIBUTING.md)
for the shared development environment and configuration checks.
